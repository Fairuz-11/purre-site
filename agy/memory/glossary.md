# Project Glossary

## Business & Domain

- **PUREE**: Construction and architectural design company based in Malang, East Java, Indonesia.
- **Kontraktor Bangunan**: Structural and general building contractor services.
- **Renovasi Bangunan**: Commercial and residential refurbishment and renovation services.
- **Desain Arsitektur**: Architectural design, facade modeling, and construction blueprints.
- **Desain Interior**: Interior architecture, spatial planning, and interior detailing.

## Technical Terms

- **SSG**: Static Site Generation in Next.js App Router.
- **`generateStaticParams`**: Function used in Next.js 16 to statically pre-render dynamic segments (`[slug]`).
- **`Turbopack`**: Next.js bundler configured with Tailwind CSS v4 loaders.
- **`motion/react`**: Modern package import for Motion (Framer Motion v14+).
